## Overview

Cognitive Computing sits where AI meets human-style reasoning — knowledge representation, expert systems, fuzzy logic, and perception-driven decision making. This repository contains the lab work and the **final project** I submitted for the course.

---

## Contents

| Notebook | What it covers |
| --- | --- |
| `Download.ipynb` | Data acquisition / preprocessing pipeline used by the rest of the project |
| `Main.ipynb` | Core experiments and walkthrough |
| `Final Project.ipynb` | End-to-end final submission — the consolidated project |

---

## Topics Touched

- Knowledge representation
- Probabilistic reasoning under uncertainty
- Cognitive architectures and decision support
- Hands-on classification / clustering applied to a cognitive-task dataset
